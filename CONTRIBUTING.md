# Contributing

> [!IMPORTANT]
> **Outside contributions are not being accepted yet.** The project is in active
> single-maintainer development; pull requests are not being merged. See the
> notice at the top of [README.md](./README.md).
>
> The guidance below is the standard the codebase is held to, and it is what
> contributions will be reviewed against once the project opens up.

## Development Principles

1. Evidence-grounded outputs only.
2. Deterministic detection before AI interpretation.
3. AI proposes, policy decides, executor acts.
4. All remediation must support verification.
5. High-risk actions require approval.
6. Knowledge promotion requires validation.

## Issue Types

- Architecture
- Backend
- Frontend
- Agent
- SOC
- GRC
- Executor
- Security
- Testing
- Documentation
- DevOps

## Pull Request Checklist

- [ ] Tests added or updated
- [ ] Documentation updated
- [ ] Security impact considered
- [ ] Evidence and audit implications considered
- [ ] No unrestricted command execution added
- [ ] No secrets committed
