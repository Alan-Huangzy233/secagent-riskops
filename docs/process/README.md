# Process artifacts

Historical, one-shot material used to seed GitHub labels, milestones and issues
and to apply documentation updates between `v0.1.5` and `v0.2.4`. All of it has
already been applied. It is kept for provenance only, is not part of the product,
and its scripts assume the repository layout of the time (files at the root), so
they are not expected to run as they are.

- `github/` — issue, milestone and label definitions
- `scripts/` — the helpers that created them and applied the documentation updates
- `V01x_*.md`, `GITHUB_PROJECT_SETUP.md` — the instructions that went with them
