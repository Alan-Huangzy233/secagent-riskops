    How to read this page

    1. Fixed detection rules run every 300 s over the sshd logs and raise alerts; an attack that keeps going keeps raising them.
    2. Alerts about the same thing are merged into incidents, and each incident gets an explainable score from what its logs show.
    3. Only incidents at or above the threshold reach an analyst. Claude then reads each one and proposes escalate, dismiss or abstain; it cannot act.
    4. A fixed playbook turns a guessed password into a plan. The policy engine decides, an operator approves, and a typed executor runs it on a lab copy, verifies it and rolls back if the check fails.

    Select an incident to see why it was surfaced, what Claude said, and what happens when you respond.
